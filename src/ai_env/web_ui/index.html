Agent Overview & Architecture

A free, offline coding environment for low-latency code completion, planning, and debugging.

🔌 System Flow Architecture

VS Code Sidebar / Web UI Frontend Editor & Chat Canvas
⇳
Python HTTP Server routes request to agent, runs on :7861
⇳
Coding Agent (agent.py) manages conversation history & prompts
⇳
Inference Backend Hugging Face transformers / Ollama API

🚀 Capabilities & Feature List

  • 💬 Chat and Code: Interact with the local coder model to refactor, document, or analyze files in the sidebar.
  • ⚡ Inline Completions: VS Code autocomplete registers a ghost-text provider calling the server.
  • 📂 Files and Folders: Manage the workspace with direct file creation, editing, and saving.
  • 🌿 Git Integration: Live diff rendering and automatically generated commit summaries.
  • 🧠 100% Offline: Operates entirely on-device, preserving privacy with zero external telemetry.

💡 Usage Guidelines

Explain & Refactor

Click on files in the explorer to open them, edit them directly, or ask the agent to optimize their implementation.

Draft Commits

Save code to automatically trigger a git diff, update the suggested commit message, and maintain history.

VS Code Support

Open the VS Code extension folder, compile, and debug. Use settings to toggle inline completions or chat.
