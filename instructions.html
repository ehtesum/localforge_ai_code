Local AI Coding Agent

Step-by-step setup for a fully local, privacy-first AI coding environment powered by Ollama, Roo Code, and a fine-tuned Qwen2.5-Coder model.

Python 3.11+ Windows 11 ready Local LLM 100% offline

1 Open this repository in VS Code

Open the project folder in Visual Studio Code. The workspace already includes recommended settings and extensions.

2 Create and activate a virtual environment

Isolate Python dependencies from the rest of your system.

3 Install required packages

Upgrade pip and install the project's dependencies. The ai_env package itself only needs the standard library; everything else is for fine-tuning.

4 Verify the environment

The ai_env CLI checks Python, ports, and required binaries.

5 Generate the Roo Code config

6 Start local services

Starts Ollama and (optionally) Roo Code as background processes.

7 Pull a model

8 Run health checks

9 Install recommended VS Code extensions

Open the Extensions panel and install everything listed in .vscode/extensions.json. The workspace will offer a one-click install on first open.

10 Use Ollama

You can talk to Ollama directly, or use it through Roo Code.

11 Launch the Web UI

A polished browser-based chat + file editor with markdown rendering, syntax highlighting, and a tabbed file tree.

12 Prepare training data

13 Train the model

14 Resume training

Re-run the same command to continue from the latest checkpoint in ./checkpoints.

Troubleshooting

Module not found

Your venv isn't activated. Run .\.venv\Scripts\Activate.ps1 on Windows or source .venv/bin/activate on Linux/macOS.

Out of memory

Use a smaller model: --model-name Qwen/Qwen2.5-Coder-1.5B, and lower --max-length.

Ollama not detected

Install from ollama.com/install and ensure the binary is on your PATH.

Port 11434 in use

Stop the conflicting process or remap the port in docker-compose.yml and src/ai_env/config.py.

VS Code extension won't load

Inside extension/: npm install && npm run compile, then press F5 to launch the dev host.

Want to start over

Run python scripts\rollback.py to stop services and uninstall the active model.

Model reference

The current model is shown in the top bar of the Web UI and in the Status panel. Change it with scripts\manage_models.py.

qwen2.5-coder:7b ⭐ Recommended

Best balance of quality and resource use for this hardware. Default in src/ai_env/config.py.

qwen3:8b

Higher quality, more capable. Use only when CPU/RAM allows.

Qwen/Qwen2.5-Coder-1.5B

Low-memory training & inference. Great when you hit OOM errors.

gpt2

Cheap smoke test for the training pipeline (no code-specific knowledge).
